Seren Maintained - Kodi repository

Maintained fork of the Seren add-on for Kodi: Trakt sync, Next Up, watched history and lists working again after the June 2026 Trakt API changes, with Real-Debrid fixes included.

In Kodi, add https://klass-723.github.io/packages/ as a file manager source, then install the repository zip from it. Full instructions and source code: github.com/klass-723/plugin.video.seren
